# Testing Relay — step-by-step walkthrough

A 5-minute scripted test so you can see exactly what the plugin does and what it outputs.
Works on a **free** Figma account (uses the "dev preview" badge instead of paid Dev Mode).

## Setup

1. Open the **Figma desktop app**, create a new design file.
2. Draw a rectangle (press **R**, drag). In the Layers panel, double-click its name and rename it
   **`Button / Primary`**.
3. Run the plugin: **Plugins → Development → Relay — Handoff Intent**
   (or **Ctrl+Alt+P** if it was the last plugin run).

## Step 1 — Select the element

- Click the `Button / Primary` rectangle.
- **Expected:** the badge (top-right of the panel) reads **design**; the line below shows
  **▸ Button / Primary**; the list shows **"No intent captured on this element yet."**
- If you see "Select a single element," you have more than one layer selected — click just one.

## Step 2 — Add an Interaction note

- The **Interaction** tab is active. Fill:
  - **Trigger:** `Tap / Click`
  - **What happens:** `navigates to checkout`
  - **Motion / timing:** `fade 150ms`
- Click **Add to handoff**.
- **Expected:** the form clears and a card appears below:
  - heading **INTERACTION** with a grey **draft** pill
  - three lines: Trigger / What happens / Motion timing

## Step 3 — Add an Accessibility note

- Click the **A11y** tab. Fill:
  - **Role:** `button`
  - **Accessible name / label:** `Checkout`
  - **Keyboard & focus:** `Enter/Space activates`
- Click **Add to handoff**.
- **Expected:** a second card appears (ACCESSIBILITY, draft).

## Step 4 — Mark one Ready

- Click the grey **draft** pill on the Accessibility card.
- **Expected:** it turns **green** and reads **ready**. (Click again to toggle back.)

## Step 5 — See the developer view

- Click the **design** badge (top-right).
- **Expected:** badge turns **blue → "dev preview"**; the authoring form disappears; a grey
  "Developer view — read only" note appears; the cards show **without** the "delete" link
  (developers can't edit, only read).

## Step 6 — Export the spec

- Click **Export Markdown**.
- **Expected:** a text box appears at the bottom, pre-selected (ready to **Ctrl+C**), containing:

```markdown
# Handoff spec — Page 1

_Generated by Relay._

## Button / Primary

**Interaction** — _draft_
- **Trigger:** Tap / Click
- **What happens:** navigates to checkout
- **Motion / timing:** fade 150ms

**Accessibility** — _ready_
- **Role:** button
- **Accessible name / label:** Checkout
- **Keyboard & focus:** Enter/Space activates

```html
<element role="button" aria-label="Checkout">
```
```

- Paste that into a PR description, a Jira/Linear ticket, or a Markdown doc — that's the handoff spec.

## Step 7 — Confirm it persists

- Click the **dev preview** badge again to return to **design**.
- Close the plugin, re-run it (**Ctrl+Alt+P**), reselect `Button / Primary`.
- **Expected:** both notes are still there — they're stored on the layer in the file.

## What "good" looks like

- Authoring feels like **filling a checklist**, not writing freeform notes.
- The export is a **structured spec with ready-to-paste ARIA**, not a note dump.
- If, after this, it still feels like "just notes" to you — that's the signal the wedge is too thin
  vs Figma's native annotations, and worth pivoting. If it feels genuinely useful at handoff,
  that's the green light to add more intent types and ticket/Storybook export.

## Notes & gotchas

- **Export covers the whole page**, not just the selected element — it gathers every annotated layer.
- Adding notes only works in **design** mode (or a real paid Dev seat is read-only by design).
- Nothing leaves your machine — the plugin has **no network access** and stores notes on the file.
