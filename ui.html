About Snapship

Snapship turns the design changes you make in Figma into a pull/merge request — a written change log, a machine-readable manifest (changes.json), and a screenshot of each changed element — so developers and AI agents can implement them from a PRD.

How it works
  1. Select a frame or element in Figma.
  2. Describe what changed, and Add change.
  3. Commit Changes → opens a PR/MR in your repo (or Download as ZIP).
  4. Point your own AI coding agent (Cursor, Claude Code, etc.) at the branch — it reads changes.json + screenshots to implement the changes (and your PRD, if you linked one).
